# Solène Avril - Portfolio Photographe

Site web d'une photographe d'art fictive, réalisé dans le cadre d'un projet fil rouge en formation.

## Voir le site en ligne

[https://baritasse.github.io/Fil_rouge/](https://baritasse.github.io/Fil_rouge/)

## Description

Maquette HTML/CSS responsive d'un portfolio de photographe d'art.
Le site s'adapte aux trois formats : ordinateur, tablette et mobile.

## Technologies utilisées

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts (Yeseva One, Montserrat)
- Font Awesome (icônes)
- Lorem Picsum (images aléatoires)

## Responsive

- **Ordinateur** : 4 colonnes, 15 photos
- **Tablette** : 4 colonnes, 12 photos
- **Mobile** : 3 colonnes, 9 photos

## Validation W3C

- HTML validé sans erreur
- CSS validé sans erreur
